01

The routine

12 minutes on a bad day

The app runs on your own machine and keeps everything in one SQLite file, so it remembers exactly where you stopped — mid-question, mid-session, mid-week. Start it with npm run dev and open localhost:3000.

Every day

One warm-up

Six to ten items drawn from the errors you are actually still making, weighted by severity and how recently you made them. This alone keeps the streak.

Most days

A topic block

Ten items on whatever the prerequisite graph says is next. Recognition first, unaided production last.

When it fits

A Gauntlet Run

Ten items, three lives, timed, drawn only from live errors. Scored against your own previous runs.

After every class with Lorena. Upload the transcript. The app segments your turns, proposes findings, and waits — nothing reaches the error log until you accept it. A correct form used unprompted is what unlocks a topic's boss fight, and it can only come from a transcript, never from a drill.
What «mastered» costs. Twelve attempts at 80%, then two clean spaced reviews at +3 and +10 days, then one spontaneous correct use in a real conversation, and finally a twelve-item unaided challenge with no hints and no retries. Fail that last one and the topic goes back to studying. It is meant to be expensive.

03

Lexicon

chosen for the job, not for a frequency list

A word earns a place here if it appears in a Lima infrastructure consultant's week and its absence would force a paraphrase. That excludes plenty of ordinary B2 vocabulary and includes some a general course would call C1 — «adenda», «valorización», «penalidad» are not advanced, they are Tuesday.

04

Backup

the only copy is on your laptop

There is no account and no cloud — the database file is the account. That is why closing the lid mid-question loses nothing, and why a lost laptop would lose everything.

Weekly, from the app

  1. Open Settings (the gear, top right).
  2. Download backup — one self-contained file. Safe to press mid-session.
  3. Drop it in iCloud Drive, or anywhere that outlives the laptop.

Or from the terminal

npm run backup
npm run backup -- --list

Moving to a new MacBook

  1. Clone the repo, then npm install.
  2. npm run dev, open Settings.
  3. Restore from a backup and pick the file.
It will not let you overwrite progress by accident. Restore shows what is in the file next to what it would replace, and refuses unless you confirm. Even then the database being replaced is copied aside first, so the wrong file is one restore away from being undone. A backup from an older version still works; one from a newer version is refused rather than half-understood.
